# PRD · 同绘 CoDraw v1.0

> 状态：已定稿（PM）｜交付周期：3 天｜目标：面试可演示、可上线、可讲深

## 1. 一句话

打开链接就能**多人同时画**的在线白板：PC 与手机浏览器同一套体验，断网续画，扫码入会，只读分享。

## 2. 成功标准

面试官在 5 分钟内能看到三件别人项目里看不到的东西：

1. **真实的多人实时协作**（两台设备同屏演示，含手机）
2. **真实的分布式能力**（一条命令起两个后端实例，跨实例同步不断）
3. **真实的工程数字**（压测报告：并发连接、消息吞吐、p95 延迟，附带 CI 与架构决策记录）

## 3. 用户与场景

| 角色 | 诉求 |
|---|---|
| 面试官 / 访客 | 不做任何配置，打开链接 10 秒内看懂并上手 |
| 房间创建者 | 建房间、分享链接/二维码、控制只读分享 |
| 协作者 | 输入昵称即加入，实时看到彼此笔迹与光标 |
| 只读访客 | 通过分享链接围观，可缩放不可改 |
| 弱网 / 移动用户 | 地铁里断网继续画，恢复后自动合并 |

## 4. 功能范围

### P0（必须完成，缺一不可）

| # | 功能 | 验收要点 |
|---|---|---|
| F1 | 建房间 | 生成 6 位易读房间码（31 字符集 `23456789ABCDEFGHJKMNPQRSTUVWXYZ`，排除 0/O/1/I/L）；返回可分享 URL `/r/{code}` |
| F2 | 加入房间 | 昵称 + 自动分配颜色；昵称存 localStorage；无需注册；**分享链接进入时引导设置昵称，顶栏头像可随时改** |
| F3 | 实时绘制 | 自由笔、橡皮、矩形、箭头、便签（含中文输入）；**落笔过程中协作者可见线条延伸** |
| F4 | 无限画布 | 平移（空格拖拽 / 中键 / 双指）、缩放（Ctrl+滚轮 / 双指捏合 / 按钮）、适配视图 |
| F5 | 在线存在感 | 他人光标（带昵称标签、按人着色）、在线成员列表 |
| F6 | 断线重连 | 本地保留未确认操作；重连后按 seq 补齐，**零丢失、无重复**；离线期间继续可画 |
| F7 | 持久化 | 服务端权威事件日志 + 周期快照；服务重启后房间内容可恢复 |
| F8 | 只读分享 | 生成带签名的只读链接；只读端可平移缩放，绘制请求被服务端拒绝 |
| F9 | 连接状态 | 顶部状态胶囊：已连接 / 重连中 / 离线，附待同步条数 |
| F9b | 画笔颜色 | 9 色可选；**默认取自己的头像色**，多人同时绘制时颜色自然区分 |
| F10 | PWA | manifest + 可安装 + 离线壳；手机「添加到主屏幕」 |
| F11 | 运维面板 | `/ops` 实时展示连接数、房间数、消息速率、p95 广播延迟、运行时长 |
| F12 | 部署 | 单文件二进制（前端 `go:embed` 内嵌）；`make binaries` 产出 Linux/Windows 双平台 |

### P1（有余力才做，按此顺序）

1. 导出 PNG（客户端合成）
2. 撤销 / 重做（仅本人操作，逆操作入日志）
3. 历史回放（按事件日志时间轴播放）
4. 激光笔（临时高亮，不落库）

### 明确不做

iOS 原生、账号体系 / OAuth、团队与权限管理、音视频、图片上传、CRDT、多白板页面。

## 5. 体验与视觉基线

- 定位：**纸感极简**，工具让位于内容。禁止花哨渐变与玻璃拟态堆砌。
- 色彩令牌：纸底 `#F7F6F2`｜墨色 `#16181D`｜主色 `#3D5AFE`｜成功 `#12B886`｜警示 `#E8590C`｜描边 `#E4E2DA`
- 字体：UI 用系统无衬线（含中文回退），房间码与数字用等宽字体
- 布局：桌面左侧竖向工具条 + 顶部房间栏；移动端底部横向工具条 + 顶部紧凑房间栏，安全区适配
- 交互底线：所有可点区域 ≥ 44px；触控与鼠标同一套 Pointer Events；无右键依赖
- 首屏：无登录墙，首页 3 秒内可建房间

## 6. 技术约束（架构师据此细化，不得擅自更换）

- 后端：**Go 1.27**，标准库 `net/http` 路由，WebSocket、Postgres、Redis 可选；单二进制，`go:embed` 托管前端产物
- 前端：**Vue 3 + TypeScript + Vite + Pinia**，Canvas 2D 渲染，PWA
- 数据：Postgres 存房间 / 事件日志 / 快照；Redis 仅用于多实例广播与跨实例序号，**单实例内存模式必须零依赖可跑**
- 部署：`CGO_ENABLED=0` 静态编译，前端产物经 `go:embed` 进二进制；**单文件交付**，Linux 23MB / Windows 24MB
- 端口：后端 8080，前端开发 5173（代理 `/api` 与 `/ws`）
- 仓库：`backend/`（Go 专家独占）、`web/`（Vue 专家独占）、`docs/`（架构师独占）、`scripts/`、根级 README 与 compose 由 PM 协调
- 环境：开发与验证全部在 WSL Ubuntu 24.04；Go 用 gvm 的 1.27.3；Node 用 nvm（24.18 LTS 为准，26.13 可回退）

## 7. 性能与可靠性目标（写进简历的数字）

| 指标 | 目标 |
|---|---|
| 单房间并发客户端 | ≥ 100 同时绘制不卡顿 |
| 广播端到端延迟（同区域） | p95 < 80ms |
| 单实例连接数 | ≥ 1000 稳定 10 分钟 |
| 消息吞吐 | ≥ 5k msg/s 不 OOM |
| 断网 60s 重连 | 增量补齐，0 丢失、0 重复 |
| 冷启动到可绘制 | < 2s（本地） |
| 数据安全 | 单条消息 ≤ 64KB，单人 60 ops/s 限流，越权写返回拒绝 |

## 9. 演示脚本（5 分钟）

1. 首页建房间 → 笔记本出画面 → 手机扫二维码加入
2. 两端同时画：矩形、箭头、便签中文输入，光标实时可见
3. 手机开飞行模式继续画 → 恢复网络 → 笔迹自动补齐，状态胶囊回到「已连接」
4. 生成只读链接 → 新标签打开 → 尝试绘制被拒，提示「只读模式」
5. 终端起第二个实例（不同端口）→ 再开一个标签 → 跨实例同步正常
6. 打开 `/ops` 面板与压测报告 → 讲并发模型、背压、序号与快照取舍

## 10. 风险与预案

| 风险 | 预案 |
|---|---|
| 跨实例序号分配复杂 | 单实例内存模式为基线，Redis 模式用 INCR 分配序号 + 客户端缺口缓冲；压测先跑单实例 |
| 便签中文输入法兼容 | 用 HTML textarea 浮层编辑，提交时转为图形，规避 canvas 直接输入 |
| 免费云休眠 / 冷启动 | 面试前 10 分钟预热；备选 Cloudflare Tunnel 本地穿透 |
| 时间不足 | 砍 P1；再砍历史回放与导出；P0 不可砍 |

## 11. 决策记录（PM 已拍板）

- 产品名：**同绘 CoDraw**，仓库 `codraw`
- 跨端：先做 PC Web + 移动 Web，PWA 覆盖安装诉求；不做 iOS，不做安卓原生包
- 实时方案：**服务端权威事件日志 + 单调 seq**，客户端乐观渲染 + 重连补齐；不上 CRDT
- 单实例零依赖可跑，Redis/Postgres 作为生产增强，用 `BROKER` 与 `STORE` 开关切换
