# 产品细节规范 · CoDraw v1.0

> 由 PM 维护。架构师与两位开发按此实现；与本文件冲突时以本文件为准（技术实现细节以 `docs/PROTOCOL.md` 为准）。

## 1. 房间码

- 长度 6 位，字符集 `23456789ABCDEFGHJKMNPQRSTUVWXYZ`（31 字符，排除 0/O/1/I/L；**已确认不含 L**）
- 生成方式：密码学随机；冲突时重试
- **统一大写展示**，输入时自动转大写
- 可读性：UI 上分组显示为 `ABC-DEF`，实际存储与 URL 不带连字符
- 分享链接：`https://{host}/r/{CODE}`；只读：`https://{host}/r/{CODE}?rt={token}`

## 2. 昵称与身份

- 首次进入房间弹出轻量输入框：昵称（1–20 字符，允许中文）
- **通过分享链接进入且从未设置过昵称时，自动弹出引导**（默认名`访客-xxxx`别人认不出），提供「稍后再说」跳过
- 跳过或想改名：点顶栏右上角头像随时修改；**只读访客也能改名**（名字只影响 presence，不影响写权限）
- 改名需要重建 WS 会话（协议无 rename 消息），画布内容不受影响
- 昵称写入 `localStorage: codraw.name`
- 颜色由服务端按加入顺序分配调色板（8 色，见 §4），同一房间内尽量不重复
- `clientId` 由浏览器生成 UUID 存 `localStorage: codraw.cid`，刷新后视为同一用户（保留颜色与撤销栈）
- 不显示头像，用首字母圆形色块

## 3. 页面与文案

| 路由 | 内容 | 关键文案 |
|---|---|---|
| `/` | 首页：一句话定位 + 「新建白板」大按钮 + 「输入房间码」小输入 + 3 条特性（实时协作 / 断网续画 / 免注册） | 标题「同绘」；副标题「打开链接，一起把想法画出来」；按钮「新建白板」「加入」 |
| `/r/:code` | 白板房间 | 顶部：房间码（可点击复制）、在线人数、连接状态、分享、只读开关、运维入口（仅 `?debug=1` 显示） |
| 只读态 | 白板只读 | 顶部胶囊「只读模式」；尝试绘制时 toast「只读链接无法编辑，向房主申请编辑权限」 |
| 离线态 | 网络断开 | 顶部胶囊「离线 · 待同步 N 条」，图形仍可本地绘制（半透明待确认样式） |
| 404 | 房间不存在或已过期 | 「房间不存在或已过期」+「新建一个白板」按钮 |

## 7. 交互细节（验收会逐条点）

1. 新建白板：点击 → 立刻进入房间（房间码已生成），无需再点确认
2. 复制房间号：点击顶栏房间码 → 只复制**房间号本身**（`ABC-DEF`，不含链接）→ toast「房间号 ABC-DEF 已复制」
3. 分享面板：显示链接 + 二维码（客户端生成）+ 复制按钮 + 只读链接开关；**复制链接在分享面板里，顶栏只复制房间号**
4. 选择工具后画完一个图形**保持当前工具**（可连续画多个同类图形）；只有便签在提交后回到选择态（因为便签需要立即编辑）
5. 删除：选中图形按 `Delete`/`Backspace`；移动端选中后出现小浮条「删除」
6. 便签：双击画布任意处新建便签 → textarea 浮层输入 → 失焦提交；`Esc` 取消
7. 橡皮：拖动擦除整条笔迹（不做像素擦除）
8. 缩放范围 10%–800%，缩放以指针位置为锚点
9. 「适配视图」：把所有图形放入视口并居中，边距 64px
10. 断网时：工具条仍可用，图形以 60% 不透明度显示，右上角常驻「离线 · 待同步 N 条」；恢复后 1s 内全部转正
11. 只读用户：工具条隐藏，仅保留平移/缩放/适配；`Delete` 无效
12. 键盘：`V` 选择、`P` 笔、`R` 矩形、`A` 箭头、`N` 便签、`E` 橡皮、`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做、`Space` 临时平移

## 8. 空态与异常

- 空房间：画布中央淡色提示「双击任意处添加便签」+ 三点操作示意，首次绘制后消失
- 连接中：状态胶囊「连接中…」，超过 5s 变「重连中…」并出现「刷新」提示（不自动刷新）
- 服务端拒绝写（只读/限流）：本地图形回滚并 toast，不静默失败
- 房间过载（>200 人）：拒绝新连接，返回明确错误码与文案「房间人数已满」

## 9. 埋点（面试加分项，最小实现）

前端把以下事件 `POST /api/rooms/{code}/stats`（或经 WS 上送）汇总：房间创建、加入成功、首次绘制耗时、重连次数、只读访问次数。`/ops` 面板展示 Top 指标即可，不做用户级追踪。
